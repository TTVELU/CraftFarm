About CraftFarm

Built for automated farming

Farm recommendations should be fully automatic, AFK-compatible, or autoclicker-compatible. Anything requiring ongoing manual mining, killing, harvesting or collection is excluded or flagged for review.

Version notes

Current reference target: Java Edition 26.3. Tutorials can target older releases. Always verify mechanics and exact version before building; a farm marked version-dependent has not been independently tested in-game.

Official release notes: Minecraft Java 26.3

Java 26.2: Chaos Cubed release notes

Offline & privacy

Farm records, completion, queue and material checks are stored locally in this app. Internet is needed to open YouTube or official source links. No account or cloud sync is used.

Known limits

Thumbnails are bundled offline illustrations, not screenshots of exact farm builds. Tutorial links open targeted YouTube searches; individual videos and creator credits are explicitly unverified leads pending per-design audit. The materials list is a planning aid; use a matching schematic for precise quantities.
